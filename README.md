# Веб-приложение для управления личными задачами

## Актуальность темы:

Ежедневно люди забывают о каки-либо мелких задачах, особенно, если они еще не начали их выполнять. Для этого придумали некие "ремайндеры", или же просто планировщики задач. Однако, многие из них перегружены.

## Целевая аудитория:

Любой пользователь, который хочет просто и юез регистрации создать себе пометку для выполнения задачи.

## Предполагаемые функциональные возможности:

- Добавление задачи с ее описанием
- Отметка задачи как выполненной
- Удаление назначенной задачи
- Фильтрация
- Сохранение списка в кэше браузера, чтобы после перезагрузки назначенные задачи не пропадали (особенно актуально, так как мы пишем максимально простую программу, при этом с таким я еще ни разу не работал, поэтому придется прибегнуть к помощи сторонних сил)

## Используемые технологии:

- HTML
- CSS
- Чистейший насколько это возможно JavaScript, я остальные фронтовые языки даже не знаю блин
- localStorage (мне это подсказали те самые сторонние силы, будем смотреть что это и с чем едят, но выглядит как что-то суперпростое)

## Ожидаемый результат:

- Выполненная практика (это важно)
- Готовая программа, ее код в этом репозитории
- Наикрутейший ремайндер (хотя тут до меня доперло, что это по сути не ремайндер, ведь они именно напоминают, а тут получится чисто задачник)
